# ATHAR — concept website

Concept site for a fictional Beirut perfume house. A real-time 3D glass perfume bottle that splits into three crystal layers while you scroll.

**Stack:** Three.js, GSAP, Node build script

**Run:** `npm install`, `node build.mjs`, then open `dist/index.html` or run `node serve.mjs`.

Built by [Ali Houssein Ballout](https://asdesignlb.com/developer) (AS Design LB).
